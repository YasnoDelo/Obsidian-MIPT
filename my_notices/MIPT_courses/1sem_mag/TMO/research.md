# Двухфазная система с конечными очередями и общей конечной орбитой

## 1. Постановка и границы исследования

Исследуется последовательное обслуживание одной заявки в двух узлах. После завершения первой фазы заявка немедленно освобождает первый прибор и пытается поступить во второй узел. При переполнении любого узла заявка направляется на общую орбиту. Все повторные попытки направлены в первый узел: после отказа второго узла первая фаза выполняется заново. Межконцевая задержка отсчитывается от первоначального внешнего поступления, а не от последней повторной попытки.

Принятые совместно с заказчиком допущения:

- Внешний поток — пуассоновский с интенсивностью $\lambda>0$, поступает только в первый узел.
- В узле $i$ один прибор; независимое экспоненциальное время обслуживания имеет параметр $\mu_i>0$. Порядок обслуживания — FCFS.
- Вместимость $C_i\geq1$ включает обслуживаемую заявку. Вместимость очереди ожидания равна $C_i-1$.
- На орбите не более $K$ заявок. Каждая независимо повторяет попытки через экспоненциальные интервалы с параметром $\nu>0$.
- Неудачная попытка с орбиты оставляет заявку на орбите. Она не является окончательной потерей, в том числе при полной орбите.
- Окончательная потеря возникает при невозможности размещения новой для орбиты заявки. Предельного числа попыток и ухода по терпению нет.
- Все часы независимы. Передача между узлами и перемещение на орбиту мгновенны.

Главные показатели — вероятность окончательной потери внешней заявки $P_{\mathrm L}$ и условное среднее время успешного завершения $W_{\mathrm S}$. Исследуется стационарный режим. Единица времени условная; параметры экспериментов являются модельными, а не измеренными характеристиками реальной сети.

Ниже приведён собственный вывод для согласованной модели. Ссылки [1–2] относятся к применяемым общим результатам, а не к утверждению, что данная конкретная система исследована в этих статьях. Обзор всех публикаций о повторных вызовах и установление научной новизны не выполнялись. Требования конкретного положения о ВКР не проверены: документ не предоставлен.

## 2. Марковская модель численностей

Пусть

$$
X(t)=(N_1(t),N_2(t),R(t)),\qquad
\mathcal E=\{0,\ldots,C_1\}\times\{0,\ldots,C_2\}\times\{0,\ldots,K\}.
$$

Из отсутствия памяти экспоненциальных распределений следует, что условные интенсивности будущих изменений зависят только от $X(t)$. Поэтому $X$ — непрерывная марковская цепь. Для $x=(i,j,r)$ ненулевые переходы между разными состояниями задаются таблицей; при совпадении назначений интенсивности складываются.

| Событие | Условие | Новое состояние | Интенсивность |
|---|---|---|---|
| Внешнее поступление в узел 1 | $i<C_1$ | $(i+1,j,r)$ | $\lambda$ |
| Внешнее поступление на орбиту | $i=C_1,\ r<K$ | $(i,j,r+1)$ | $\lambda$ |
| Успешная повторная попытка | $r>0,\ i<C_1$ | $(i+1,j,r-1)$ | $r\nu$ |
| Завершение фазы 1, переход в узел 2 | $i>0,\ j<C_2$ | $(i-1,j+1,r)$ | $\mu_1$ |
| Завершение фазы 1, переход на орбиту | $i>0,\ j=C_2,\ r<K$ | $(i-1,j,r+1)$ | $\mu_1$ |
| Потеря после фазы 1 | $i>0,\ j=C_2,\ r=K$ | $(i-1,j,r)$ | $\mu_1$ |
| Успешное завершение фазы 2 | $j>0$ | $(i,j-1,r)$ | $\mu_2$ |

Внешнее поступление при $i=C_1,r=K$ теряется, не изменяя $X$. Неудачная повторная попытка также не меняет $X$. Эти события не включаются во внедиагональные элементы генератора и не увеличивают его диагональную интенсивность выхода. В имитации они учитываются как физические события.

$$
q_{xx}=-\sum_{y\ne x}q_{xy},\qquad Q\mathbf1=0.
$$

### Существование единственного стационарного распределения

Из каждого состояния имеется конечная последовательность событий с положительной вероятностью, которая опустошает систему: внешние поступления отсутствуют достаточно долго, второй узел освобождается, заявки первого узла проходят во второй, затем заявки орбиты поочерёдно проходят оба узла. Порядок событий можно выбрать так, чтобы не возникало отказа при передаче между узлами.

Следовательно, пустое состояние достижимо из любого состояния. В конечной цепи каждый замкнутый класс должен содержать пустое состояние; замкнутый класс единственен. Стационарное распределение существует и единственно, независимо от отношения $\lambda$ к $\mu_i$. Возможные состояния вне этого класса имеют нулевую стационарную вероятность. Конечность вместимостей снимает требование вида $\lambda<\min(\mu_1,\mu_2)$ для существования стационарного распределения.

Обозначим стационарные вероятности через $\pi_{ijr}$. Они являются единственным нормированным неотрицательным решением:

$$
\pi Q=0,\qquad \pi\mathbf1=1.
$$

Это конечная система линейных уравнений порядка

$$
M=(C_1+1)(C_2+1)(K+1).
$$

В программе одна строка системы $Q^{\mathsf T}\pi^{\mathsf T}=0$ заменяется условием нормировки. Здесь «аналитический расчёт» означает точное задание конечной модели и численное решение её линейных уравнений, без аппроксимации независимостью узлов и без усечения бесконечной орбиты. Числа вычисляются с машинной точностью, а не в символической арифметике.

## 3. Вероятность окончательных потерь

Стационарная интенсивность мгновенных потерь внешних заявок:

$$
\ell_0=\lambda\sum_{j=0}^{C_2}\pi_{C_1,j,K}.
$$

Интенсивность потерь после обслуживания в первом узле:

$$
\ell_1=\mu_1\sum_{i=1}^{C_1}\pi_{i,C_2,K}.
$$

Заявка может многократно возвращаться на орбиту, но окончательно потеряться может только один раз. Все заявки имеют внешний источник. Поэтому искомая вероятность равна
#важно

$$
\boxed{P_{\mathrm L}=\frac{\ell_0+\ell_1}{\lambda}
=\sum_{j=0}^{C_2}\pi_{C_1,j,K}
+\frac{\mu_1}{\lambda}\sum_{i=1}^{C_1}\pi_{i,C_2,K}.}
$$

**Доказательство.** Пусть $A(t)$ — число внешних поступлений, $D(t)$ — число успешных завершений, $B(t)$ — число окончательных потерь до времени $t$, а $N=N_1+N_2+R$. Для каждой траектории

$$
N(t)-N(0)=A(t)-D(t)-B(t).
$$

Разность между числом потерь по времени события и числом потерянных заявок когорты поступлений ограничена числом заявок на границах интервала. Оно не превосходит $2(C_1+C_2+K)$. После деления на $t$ эта разность исчезает. По эргодическому усреднению интенсивность $B$ равна $\ell_0+\ell_1$, а интенсивность $A$ равна $\lambda$. Получаем формулу. Конечность времени до исхода обосновывается в разделе 4.

Успешная пропускная способность:

$$
\theta=\mu_2\sum_{i=0}^{C_1}\sum_{j=1}^{C_2}\sum_{r=0}^{K}\pi_{ijr}.
$$

Из того же баланса следуют контрольные тождества:

$$
\boxed{\lambda=\theta+\ell_0+\ell_1,\qquad
P_{\mathrm L}=1-\frac{\theta}{\lambda}.}
$$

Вероятность мгновенной потери не равна вероятности окончательной потери: первая учитывает только $\ell_0/\lambda$. Вероятность отказа узла с переходом на орбиту также не является вероятностью окончательной потери.

## 4. Межконцевая задержка успешных заявок

### 4.1. Почему недостаточно численностей

Численности достаточны для потерь и пропускной способности, но не определяют оставшееся время конкретной заявки при FCFS. Заявка может стоять первой или последней в одной и той же очереди. Для условной задержки вводится отмеченная внешняя заявка.

Пусть $\tau$ — время от её внешнего поступления до окончательного выхода, а $S$ — событие успешного завершения обеих фаз. Требуется

$$
W_{\mathrm S}=\mathbb E[\tau\mid S].
$$

У мгновенно потерянной заявки $\tau=0$. Время до последующей потери положительно и не входит в $W_{\mathrm S}$.

### 4.2. Пространство состояний отмеченной заявки

Используется состояние

$$
z=(a,b,r,o).
$$

Здесь $a$ и $b$ — упорядоченные последовательности нулей и единиц в узлах 1 и 2; первый элемент обслуживается. Ноль обозначает обычную заявку, единица — отмеченную. Число обычных заявок на орбите равно $r$, а $o\in\{0,1\}$ показывает наличие отмеченной заявки на орбите. Допустимы состояния

$$
|a|\leq C_1,\quad |b|\leq C_2,\quad r+o\leq K,\quad
\sum a+\sum b+o=1.
$$

Обычные заявки взаимозаменяемы благодаря одинаковым независимым экспоненциальным часам. Номера обычных заявок для этого расчёта не нужны. Верхняя граница числа состояний:

$$
M_*=(K+1)\left[(C_2+1)\frac{C_1(C_1+1)}2
+(C_1+1)\frac{C_2(C_2+1)}2\right]
+K(C_1+1)(C_2+1).
$$

Добавляются два поглощающих исхода: успех $S$ и потеря $L$.

Правила переходов полностью определяют матрицу:

1. Внешнее поступление интенсивности $\lambda$ добавляет обычную заявку в конец $a$, если есть место; иначе увеличивает $r$, если на орбите есть место; иначе теряется без изменения состояния отмеченной заявки.
2. При непустом $a$ с интенсивностью $\mu_1$ удаляется первый элемент. Он добавляется в конец $b$, если есть место. Иначе поступает на орбиту: для нуля увеличивается $r$, для единицы устанавливается $o=1$. При полной орбите единица поглощается в $L$, ноль исчезает, а цепь отмеченной заявки продолжается.
3. При непустом $b$ с интенсивностью $\mu_2$ удаляется первый элемент. Единица поглощается в $S$; удаление нуля оставляет отмеченную заявку в системе.
4. Обычные заявки орбиты совершают попытки с интенсивностью $r\nu$. При свободном месте ноль добавляется в конец $a$, а $r$ уменьшается на единицу.
5. Отмеченная заявка орбиты совершает попытки с интенсивностью $o\nu$. При свободном месте единица добавляется в конец $a$, а $o$ становится нулём. Неудачные попытки не изменяют состояние.

Пусть $T$ — матрица переходных интенсивностей между непоглощающими состояниями. Векторы $b_{\mathrm S}$ и $b_{\mathrm L}$ содержат интенсивности поглощения. В диагонали $T$ учитываются также выходы в поглощение:

$$
T\mathbf1+b_{\mathrm S}+b_{\mathrm L}=0.
$$

**Лемма о поглощении.** Из любого состояния отмеченной заявки существует конечный путь к успешному завершению с положительной вероятностью: запретить внешние поступления на конечном интервале, последовательно освободить узел 2 и обеспечить продвижение отмеченной заявки. Если она на орбите, обеспечить её попытку после освобождения узла 1. Число состояний конечно, поэтому можно выбрать общие $t_0>0$ и $\varepsilon>0$, для которых вероятность поглощения за $t_0$ из любого состояния не меньше $\varepsilon$. По марковскому свойству

$$
\Pr_z\{\tau>nt_0\}\leq(1-\varepsilon)^n.
$$

Отсюда поглощение происходит почти наверное, все моменты $\tau$ конечны, $e^{Tt}\to0$, а $-T$ обратима.

### 4.3. Вероятность успеха и взвешенное время

Определим столбцы

$$
h_z=\Pr_z(S),\qquad g_z=\mathbb E_z[\tau\mathbf1_S].
$$

Интенсивность успешного поглощения в момент $t$ при начальном состоянии $z$ равна $[e^{Tt}b_{\mathrm S}]_z$. Интегрирование даёт

$$
h=\int_0^\infty e^{Tt}b_{\mathrm S}\,dt=(-T)^{-1}b_{\mathrm S}.
$$

Первый момент с индикатором успеха равен

$$
g=\int_0^\infty t e^{Tt}b_{\mathrm S}\,dt=(-T)^{-2}b_{\mathrm S}=(-T)^{-1}h.
$$

Граничные члены при интегрировании по частям исчезают по лемме. Эквивалентные линейные системы:

$$
\boxed{(-T)h=b_{\mathrm S},\qquad (-T)g=h.}
$$

Матрица в обеих системах одинакова. Программа решает системы, не вычисляя обратную матрицу явно.

### 4.4. Состояние при внешнем поступлении

Внешний пуассоновский поток не предвосхищает состояние системы, поэтому видит стационарные вероятности $\pi$ по свойству PASTA [1]. Обозначим через $\alpha$ строку начальных вероятностей непоглощающих состояний отмеченной заявки. Для каждого $(i,j,r)$:

$$
(i,j,r)\mapsto
\begin{cases}
(0^i1,0^j,r,0),&i<C_1,\\
(0^i,0^j,r,1),&i=C_1,\ r<K,\\
L,&i=C_1,\ r=K.
\end{cases}
$$

Здесь $0^i$ — последовательность из $i$ нулей. Вес соответствующего состояния увеличивается на $\pi_{ijr}$. Если

$$
p_0=\sum_j\pi_{C_1,j,K},
$$

то $\alpha\mathbf1=1-p_0$. Нормировать $\alpha$ до единицы нельзя при вычислении вероятности успеха произвольной внешней заявки.

Итоговые формулы:

$$
\boxed{P_{\mathrm S}=\alpha h,\qquad
P_{\mathrm L}=1-\alpha h,\qquad
W_{\mathrm S}=\frac{\alpha g}{\alpha h}.}
$$

Это точный матричный вывод условной задержки с учётом очередей, орбиты и любого числа повторных прохождений первой фазы.

### 4.5. Дополнительные тождества и закон Литтла

Положим

$$
u=(-T)^{-1}\mathbf1,\qquad v=(-T)^{-1}b_{\mathrm L}.
$$

Тогда $u_z=\mathbb E_z\tau$, $v_z=\Pr_z(L)$, а

$$
h+v=\mathbf1,\qquad P_{\mathrm L}=p_0+\alpha v.
$$

Среднее время до любого окончательного исхода:

$$
W_{\mathrm{exit}}=\alpha u.
$$

Обозначим

$$
\overline N=\sum_{i,j,r}(i+j+r)\pi_{ijr}.
$$

Применение закона Литтла [2] ко всем внешним заявкам, включая мгновенно потерянные с нулевым временем, даёт контроль:

$$
\boxed{\overline N=\lambda W_{\mathrm{exit}}.}
$$

При $P_{\mathrm L}>0$ обозначим $W_{\mathrm L}=\mathbb E[\tau\mid L]$. По разложению полного ожидания

$$
\frac{\overline N}{\theta}
=W_{\mathrm S}+\frac{P_{\mathrm L}}{1-P_{\mathrm L}}W_{\mathrm L}.
$$

Поэтому деление общего среднего числа заявок на интенсивность успешных выходов завышает $W_{\mathrm S}$ при наличии потерь с положительным временем пребывания. Это не поправка к закону Литтла, а необходимость согласованно выбирать совокупность заявок в его числителе и знаменателе.

## 5. Имитационная модель и проверка реализации

Файл `two_phase_orbit.py` содержит независимую реализацию движения индивидуальных заявок. Каждая хранит идентификатор, первоначальное время поступления и признак принадлежности наблюдаемой когорте. Очереди реализованы упорядоченными списками обслуживания, орбита — набором заявок с одинаковыми интенсивностями попыток.

При текущих численностях суммарная интенсивность физических событий равна

$$
a=\lambda+\mu_1\mathbf1_{\{N_1>0\}}+\mu_2\mathbf1_{\{N_2>0\}}+\nu R.
$$

До следующего события генерируется интервал $\Delta\sim\operatorname{Exp}(a)$. Тип события выбирается пропорционально четырём интенсивностям. При попытке с орбиты заявка выбирается равновероятно из $R$ находящихся там заявок.

**Доказательство соответствия вероятностному механизму.** Минимум независимых экспоненциальных часов имеет параметр, равный сумме параметров. Вероятность срабатывания конкретного часа равна отношению его параметра к этой сумме. Для $R$ одинаковых часов орбиты это даёт интенсивность $R\nu$ и вероятность выбора $1/R$. После события условные остаточные времена снова экспоненциальны вследствие отсутствия памяти. Следовательно, последовательность генерируемых физических событий имеет закон согласованной модели. Исключение событий без изменения состояния даёт генератор $Q$ из раздела 2. Это доказательство метода моделирования; отсутствие всех возможных программных ошибок из него не следует.

### Когорта без цензурирования

Каждый прогон начинается с пустой системы. После прогрева $B$ в когорту включаются все внешние заявки, поступившие в интервале $[B,B+H)$. Затем имитация продолжается до исхода последней заявки этой когорты. Внешний поток при донаблюдении не отключается: его отключение изменило бы условия для оставшихся заявок.

Для прогона $m$ при $A_m$ поступлениях, $L_m$ потерях и $S_m$ успешных исходах используются оценки

$$
\widehat P_m=\frac{L_m}{A_m},\qquad
\widehat W_m=\frac{1}{S_m}\sum_{k\in\mathcal S_m}(t_k^{\mathrm{out}}-t_k^{\mathrm{in}}).
$$

Точно проверяется $A_m=L_m+S_m$. Наблюдения соседних заявок зависимы; применять формулу стандартной ошибки для независимых заявок здесь нельзя. Используются независимые прогоны с разными начальными состояниями генератора случайных чисел.

Дополнительно измеряются: число успешных выходов именно в окне, делённое на $H$; интеграл $N(t)$ по окну, делённый на $H$; среднее время до любого исхода по всей когорте. Эти оценки проверяют $\theta$, $\overline N$ и $W_{\mathrm{exit}}$ соответственно.

### Интервалы и критерий согласованности

Для $m=1,\ldots,n$ обозначим оценку любого показателя через $Y_m$. Тогда

$$
\overline Y=\frac1n\sum_mY_m,\qquad
s_Y^2=\frac1{n-1}\sum_m(Y_m-\overline Y)^2,\qquad
\operatorname{SE}=\frac{s_Y}{\sqrt n}.
$$

Приближённый индивидуальный 95%-й интервал:

$$
\overline Y\pm t_{n-1;0.975}\operatorname{SE}.
$$

Проверяются пять показателей в трёх сценариях, всего $J=15$ сравнений. Также вычисляются интервалы с поправкой Бонферрони:

$$
\overline Y\pm t_{n-1;1-0.05/(2J)}\operatorname{SE}.
$$

Семейный уровень 95% является приближённым, поскольку сами интервалы Стьюдента опираются на приближённую нормальность оценок по длинным прогонам. Он относится к основной серии из 15 сравнений, не ко всем дополнительным диагностическим экспериментам. Оценки отношений могут иметь конечновыборочное смещение. Прогрев уменьшает, но сам по себе не доказывает отсутствие начального смещения.

### Детерминированные проверки

Программа проверяет нормировку и невязку стационарного решения, уравнения для $h$ и $g$, тождество $h+v=1$, совпадение двух способов вычисления потерь, баланс потоков и равенство $\alpha u=\overline N/\lambda$. Для невязок отмеченной цепи используется масштабирование, чтобы большие интенсивности не приводили к ложному отказу проверки из-за округления.

Независимый малый пример: $C_1=C_2=1$, $K=0$, $\lambda=\mu_1=\mu_2=1$. В порядке $(0,0),(0,1),(1,0),(1,1)$:

$$
\pi=\frac18(2,2,3,1),\qquad
\theta=\frac38,\qquad P_{\mathrm L}=\frac58,\qquad
\overline N=W_{\mathrm{exit}}=\frac78.
$$

После поступления в пустую систему успех гарантирован и средняя задержка равна $2$. При поступлении в состояние $(0,1)$ успех требует, чтобы второй прибор освободился раньше завершения первой фазы: вероятность $1/2$, условная задержка $1/2+1+1=5/2$. Остальные поступления теряются немедленно. Поэтому

$$
W_{\mathrm S}=\frac{(1/4)\cdot2+(1/4)(1/2)(5/2)}{1/4+(1/4)(1/2)}=\frac{13}{6}.
$$

Эти рациональные значения проверяются программой. Дополнительно проверяются два предела: при $\mu_2\to\infty$, $C_1=C_2=1,K=0,\lambda=\mu_1=1$ вероятность потерь стремится к $1/2$; при $\lambda\to0$ задержка стремится к $1/\mu_1+1/\mu_2$.

## 7. Интерпретация и границы подтверждения

При увеличении $\lambda$ с 0.6 до 1.4 вероятность потери в выбранной системе выросла с 3.5181% до 39.2499%, а условная задержка — с 3.026726 до 4.900572. Это сравнение двух заданных режимов, а не доказательство общей монотонности.

При фиксированной $\lambda=1.4$ уменьшение $\nu$ с 0.8 до 0.15 повысило потери на 3.9202 процентного пункта и условную задержку на 10.1676%. Пропускная способность уменьшилась с 0.850502 до 0.795619.

Сопоставление подходов в данной работе:

| Метод | Что вычисляет | Ограничение |
|---|---|---|
| Цепь численностей $Q$ | Потери, пропускную способность, среднюю численность | Не хранит положение отдельной заявки |
| Цепь отмеченной заявки $T$ | Вероятность успеха и условную межконцевую задержку | Число состояний растёт с вместимостями |
| Имитация индивидуальных заявок | Те же показатели по траекториям и когортам | Статистическая ошибка, возможное начальное смещение |
| Отношение $\overline N/\theta$ | Суммарное время всех заявок на один успешный выход | В общем случае не равно задержке успешной заявки |

Математически доказаны: корректность задания генераторов при принятых допущениях, существование единственного стационарного распределения, формулы потерь и условного среднего времени, а также соответствие алгоритма экспоненциальных гонок вероятностной модели. Численно проверены: матричные тождества, независимый четырёхсостоянийный пример, два предельных режима и согласование с имитацией на трёх наборах параметров.

Эти результаты подтверждают реализацию в выполненных проверках. Конечная серия имитаций не доказывает отсутствие любых ошибок программы и не подтверждает применимость экспоненциальных допущений к реальному объекту. Для такой применимости нужны наблюдения внешнего потока, времени обслуживания и повторных обращений. При изменении дисциплины очереди, закона повторов или маршрута после отказа второго узла требуется изменить модель.

## 8. Воспроизводимость

Сопровождающий файл: `two_phase_orbit.py`. Зависимости — Python, NumPy и SciPy. Выполненный расчёт использовал следующие версии:

- python: `3.12.14`.
- numpy: `2.3.5`.
- scipy: `1.17.0`.

Основная серия:

```bash
python two_phase_orbit.py --reps 24 --duration 50000 --warmup 5000 --seed 20261025 --output experiment
```

Диагностическая короткая серия:

```bash
python two_phase_orbit.py --reps 24 --duration 5000 --warmup 5000 --seed 20261025 --output short_experiment
```

При необходимости установки зависимостей:

```bash
python -m pip install numpy scipy
```

Каждый запуск сначала выполняет встроенные проверки, затем печатает результаты и сохраняет `results.json` в указанную папку. JSON содержит параметры, версии, аналитические значения, результаты каждого прогона, индивидуальные и семейные интервалы, фактические числа поступлений и исходов. Флаг покрытия интервалом является диагностикой, а не обязательным утверждением программы: случайный выход за 95%-й интервал допустим и не должен автоматически объявляться программной ошибкой.

Для иных параметров можно использовать программный интерфейс:

```python
from two_phase_orbit import Params, analytical, simulate

p = Params(lam=1.0, mu1=1.5, mu2=1.2, nu=0.8, c1=2, c2=2, k=3)
exact = analytical(p)
one_run = simulate(p, seed=12345, warmup=5000, duration=50000)
```

Для статистического сравнения нужны независимые повторения `simulate`, а не единственный прогон. В аналитике матрица численностей хранится плотной, матрица отмеченной заявки — разреженной. Реализация рассчитана на умеренные конечные вместимости; при больших значениях требуется более экономное хранение первой матрицы и пересмотр вычислительных затрат.
