1. alguno - используются в вопросах

| algo     | alguien   | alguno      |     |
| -------- | --------- | ----------- | --- |
| что-то   | кто-то    | какой-то    |     |
| **nada** | **nadie** | **ninguno** |     |
| ничего   | никто     | никакой     |     |

2. uno / una - используются в положительном смыле (не отрицание, не вопрос)
3. algo / alguien - используются в любых случаях
4. nada/nadie - только в отрицаниях
5. ninguno - только в отрицаниях

двойное отрицание возможно (когда одно отрицание проглатывается, как в "нет ничего") если местоимение после глагола.
Ejemplo: 
1) no tengo ningunos problemas (нет никаких проблем)
2) no me gusta nada = nada me gusta

можно сказать alguna/-o если не понятно, существует ли объект, и un/-a, если знаем, что объект есть и хотим узнать детали про него
1) tienes un boligrafo - знаешь, что ручка может быть и спрашиваешь, есть ли она сейчас
2) tienes algun boligrafo - не уверен, что ручка была у человека хотя бы когда-то
