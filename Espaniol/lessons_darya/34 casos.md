Caso Dativo: me te le nos os les


| Caso Dativo                                            | Caso Acusativo                      |
| ------------------------------------------------------ | ----------------------------------- |
| me                                                     | me                                  |
| te                                                     | te                                  |
| le                                                     | lo/la                               |
| nos                                                    | nos                                 |
| os                                                     | os                                  |
| les                                                    | los/las                             |
| коственное (с предлогом) дополнение, для кого действие | прямое дополнение, действие над ней |

Deberes: составить предложение, потом заменить на местоимения


1. Comro el pienso para perros
	1. Lo compro para mi perros
2. Padre regala el jugete a niño
	1. Padre lo regala a niño
	2. Padre le regala ai juego
3. Cultivas la flor para madre
	1. Le cultivas la flor
	2. La cultivas para madre
4. Damos agua a amigo
	1. Le damos agua
	2. La damos a amigo
5. Envío una foto a Pablo.
	1. Lo envío a Pablo
