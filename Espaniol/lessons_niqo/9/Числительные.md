### tener
| местоимение  | значение | tener    |
| ------------ | -------- | -------- |
| yo           | я        | tengo    |
| tú           | ты       | tienes   |
| él, ella     | он, она  | tiene    |
| nosotros     | мы       | tenemos  |
| vosotros     | вы       | tenéís |
| ellos, ellas | они      | tienen   |

### Tener+que+infinitivo - быть должным
Tengo que ir - я должен идти

hay que - нужно
