### Согласные

| буква   | произношение                                                                |
| ------- | --------------------------------------------------------------------------- |
| C       | перед e, i - "с", с остальными - "к"                                        |
| CC      | Читается как "кс"                                                           |
| Ch      | "ч"                                                                         |
| Ll      | "ль" (в традиционном диалекте)                                              |
| b, v    | в начале слова и после "m", "n" читаются как "б", в остальных случаях - "в" |
| G       | Перед e, i читается как "х", с остальными - "г"                             |
| gue/gui | гэ/ги                                                                       |
| güe     | "Гуэ" - редко встречается                                                   |
| que/qui | кэ/ки (только тут встречается "q")                                          |
| h       | глухая, не читается                                                         |
| j       | всегда "х"                                                                  |
| ñ       | нь                                                                          |
| x       | кс                                                                          |
| z       | "с"                                                                         |



### Гласные

| Сильные | Слабые  |
| ------- | ------- |
| a, o, e | i, y, u |
Дифтонги читать в один слог.


### 1-е правило ударения
Если слово заканчивается на гласную, или на согласные N, S, ударение падает на предпоследний слог. Примеры: telegrama, otros, reciben, como, poco, pronto, comes, descansas, Carmen, escuchamos

### 2-е правило ударения
Если слово оканчивается на согласную (кроме n,s), ударение падает на последний 
Примеры: profesor, tomar, azul, papel, usted, pared, salir, musical, ajedrez

### 3-е правило ударения
В остальных случаях ставится графическое ударение Примеры: lápiz, película, detrás, jardín, habitación, también, marrón, lámpara, periódico, infantería, ejército
