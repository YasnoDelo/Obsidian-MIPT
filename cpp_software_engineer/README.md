# Решения 02.01–03.06

- `src/` — 16 независимых программ C++23, по одному `.cpp` на задачу.
- `PROMPTS.md` — пользовательские запросы

Нужны компилятор и стандартная библиотека с поддержкой C++23 `<print>`. Проверено на GCC 14.2.0. 

Для запуска автопроверки нужно запустить из корня распакованного архива:

```sh
env -u LD_PRELOAD -u LD_AUDIT CXX=g++-14 bash check_all.sh
```

`-Werror` добавлен к требуемым флагам, чтобы любое предупреждение считалось ошибкой.
